# unmouse

キーボードだけでマウスを操作する macOS 用の常駐ツールです。ホットキーで起動すると、全モニターの全セルに `j` `k` `l` `;` だけのラベルを薄く表示します。目的の場所のラベルを打ち終えると、カーソルがそのセルの中心へ動いて閉じます。クリックはトラックパッドやマウスのボタンで行います。打ちかけで `Space` などを押すと、その範囲の中心でクリックして閉じます。

## 必要なもの

- macOS
- Rust（`cargo` が使えること）

ビルド:

```sh
cargo build --release
```

`.app` にまとめる場合:

```sh
scripts/bundle.sh
```

`target/release/bundle/Unmouse.app` ができます。

## 権限

初回起動時に Accessibility の許可を求めます。

- システム設定 > プライバシーとセキュリティ > アクセシビリティ で、`Unmouse.app`（またはバイナリを起動したターミナルアプリ）を許可してください。
- イベントのタップが作れない環境では、入力監視（Input Monitoring）も必要です。
- ターミナルから `cargo run` やバイナリを直接起動した場合は、権限はそのターミナルアプリに与えます。

## 署名の注意

`UNMOUSE_SIGN_IDENTITY` を指定しないと ad-hoc 署名（`-`）になります。この場合、ビルドのたびに Accessibility の再許可が必要になります。

```sh
UNMOUSE_SIGN_IDENTITY="自己署名証明書の名前" scripts/bundle.sh
```

自己署名証明書を作って指定すると再許可を避けられる見込みです。ただし、この点は未確認です。

## 使い方

1. 右 Cmd を2回タップする（既定）。全モニターにラベルが出ます。Cmd を使うショートカットは邪魔しません。
2. 目標の上のラベルを `j` `k` `l` `;` で打つ。セルが決まると、カーソルがその中心へ動いて閉じます。
3. 打ちかけで操作キーを押すと、その範囲の中心で操作して閉じます。

| キー | 動作 |
|---|---|
| `j` `k` `l` `;` | ラベルを打つ（`refine = true` のときは、セルが決まった後も細分のキーとして使う） |
| `Space` / `d` / `s` / `a` | 左クリック / 右クリック / ダブルクリック / 中クリックして終了 |
| `f` | クリックせずに終了（打ちかけなら、その範囲の中心へ動かす） |
| `g` | ドラッグの開始と終了 |
| `h` か `Backspace` | 1文字戻る |
| `Esc` か、起動の操作をもう一度（右 Cmd の2回タップ） | 取り消す |

## 設定

設定ファイルは `~/.config/unmouse/config.toml` です。`$XDG_CONFIG_HOME` が設定されていれば、その下の `unmouse/config.toml` を読みます。ファイルがなければ既定値で動きます。

全項目は `config.example.toml` を参照してください。よく変える項目は次のとおりです。

- `hotkey`: 起動の操作（既定 `"double:right_cmd"`）。トップレベルに書きます。修飾キーの2回タップは `"double:right_cmd"`（ほかに `left_cmd` `right_option` `left_option` `right_shift` `left_shift` `right_ctrl` `left_ctrl`）、キーの組み合わせは `"ctrl+alt+j"` の形で書きます。
- `double_tap_ms`: 2回タップの間隔と、1回の押下の上限（ms、100〜1000、既定 300）。トップレベルに書きます。
- `label_size`: ラベルの文字サイズ（pt、6〜48）。`[style]` に書きます。
- `label_layout`: `"center"`（既定）はセルの真ん中に1まとまりで出します。`"inline"` はセルの左上に出します。`"corners"` は4隅に1文字ずつ出します（4文字のときだけ。それ以外は `"center"` と同じ）。`[style]` に書きます。
- `key_colors`: 次に打つ文字の色（`"#rrggbb"` を4つ、`grid.keys` と同じ順）。既定は `j` 青、`k` 緑、`l` 橙、`;` 紫です。次に打つ文字は太字で、キーごとの色になります。`[style]` に書きます。
- `max_cell`: 1つのセルの最大サイズ（pt、`[width, height]`）。大きいほどセルが粗くなります。`[grid]` に書きます。
- `scope`: `"all_monitors"`（既定）は全モニターを1枚の画面として扱います。`"cursor_monitor"` はカーソルのあるモニターだけで分けます。`[grid]` に書きます。
- `refine`: `false`（既定）は、ラベルを打ち終えると閉じます。`true` は閉じずに細分のキーを出し、続けて `j` `k` `l` `;` で細かく絞れます。その間は `Space` `d` `s` `a` で、その位置をキーでクリックできます。`[grid]` に書きます。

## 複数モニター

全モニターを1枚の画面とみなします。モニターを選ぶ段はありません。モニターの境目をまたぐセルは、面積の大きい側のモニターにラベルを出します。

## サブコマンド

引数なしで起動すると `run`（常駐）になります。

| コマンド | 内容 |
|---|---|
| `unmouse run [--verbose]` | 常駐して、起動の操作で起動する（既定）。起動時に権限・tap・起動の操作を標準エラーに出します。`--verbose` で受けたキーイベントを1行ずつ出します |
| `unmouse doctor` | 権限・イベントタップ・Secure Input・設定・モニターを確かめる |
| `unmouse layout` | モニター、文字数、各モニターのセルの大きさを表示する |
| `unmouse cursor` | 今のカーソル位置を表示する |
| `unmouse path <x> <y>` | 指定した点のラベルを表示する |
| `unmouse demo --keys "<キー列>" [--delay-ms <ms>] [--allow-click]` | イベントタップなしで起動し、キーを順に流す。例: `--keys "l l k ; f"`。クリック系のキー（`space d s a g`）は既定で拒否され、`--allow-click` を付けたときだけ通ります |
